Sobre Nós

Este projeto é um clone funcional da interface do Discord desenvolvido exclusivamente para fins educacionais na disciplina de Desenvolvimento Web I.

Não possui qualquer vínculo com o Discord. Todos os usuários, servidores, canais e mensagens apresentados são inteiramente ficticios.
